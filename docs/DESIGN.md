# Theme Name: 工程蓝图
# Vibe & Description: 凭借深蓝色块与纯白线条的强烈对比保障可读性与视觉冲击力，将技术注释、尺寸标注线等作为装饰元素，通过可见精确的网格系统严格对齐所有元素并明确展示 UI “骨架”，以功能性与清晰度彰显美感。

# Color
- 基底色：工程深蓝（#0D47A1）——象征稳定与可靠 （禁止将该颜色大面积用户背景色，仅允许在小色块中出现）
- 线条色：纯白（#FFFFFF）或者网格青蓝（#2962FF），通过不透明度变化区分层级
    * 内容：100%
    * 网格：30%
- 破坏色：安全橙（#FF5722）或警示黄（#FFC107），用于 CTA，呼应施工安全配色


# Font
- Heading & Body: Source Han Mono SC (url: https://resource-static.cdn.bcebos.com/fonts/SourceHanMonoSC-Regular.woff2)
# Animation
## 元素动画
- 悬停反馈即时、生硬，无缓动效果。
- 元素交互时有“锁定到网格”的感觉。
- 有打字机效果，文字逐字符出现。
- 光标与指示器以稳定、机械的频率闪烁。
## 动画实现
- 项目中集成了 tailwindcss-intersect 插件，可以使用类似下述的方式来实现元素进入视口时的动画效果：
opacity-0 intersect:opacity-100 transition duration-700
- 同时可使用 motion/react 配合实现动画。

# Layout
- 采用模块化网格，页面通过可见的 1px 线条被划分为清晰的象限与区域。
- 采用非对称平衡，元素可跨越网格线排列。内容多贴齐底部或角落，留出负空间用于“注释”和“尺寸标记”。

# Elements
- 鼠标触发十字准星；页面边缘带尺寸刻度。
- 使用等宽小字标注区域（如 “FIG 1.1”、“SCALE 1:100”）。
- 虚线用于次级信息或关联元素的连接。
- UI 元素如同技术模块或 CAD 块，带有可见边框与角标。
- 可用生图工具生成一些工程制图的图片作为插图
