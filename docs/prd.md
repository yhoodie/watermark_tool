# 需求文档

## 1. 应用概述

### 1.1 应用名称
数字水印嵌入与提取系统

### 1.2 应用描述
本系统为Web网页应用，用于在图片、音频、视频等载体中嵌入数字水印，并支持水印提取与鲁棒性验证。系统支持批量处理、水印强度调节、可选加密功能，以及攻击模拟测试。

---

## 2. 用户与使用场景

### 2.1 目标用户
- 需要对数字内容进行版权保护的创作者
- 需要验证数字水印技术鲁棒性的研究人员
- 需要批量处理数字水印的内容管理人员

### 2.2 核心使用场景
- 场景1：用户上传图片/音频/视频文件，嵌入文字或图片水印，下载处理后的文件
- 场景2：用户上传已嵌入水印的文件，提取其中的水印内容
- 场景3：用户对已嵌入水印的文件进行攻击模拟（如格式转换、裁剪、噪声），验证水印是否仍可提取

---

## 3. 页面结构与功能说明

### 3.1 页面结构

```
数字水印嵌入与提取系统
├── 水印嵌入界面
├── 水印提取界面
└── 攻击模拟界面
```

### 3.2 功能说明

#### 3.2.1 水印嵌入界面

**3.2.1.1 载体文件上传**
  - 支持上传图片、音频、视频文件
  - 支持批量上传多个文件

**3.2.1.2 水印内容选择**
  - 支持选择水印类型：文字、图片、音频、视频
  - 文字水印：用户输入文字内容
  - 图片水印：用户上传图片文件
  - 音频水印：用户上传音频文件
  - 视频水印：用户上传视频文件

**3.2.1.3 水印强度调节**
  - 提供强度调节控件，用户可设定嵌入强度阈值
  - 说明：强度越高，水印越明显但鲁棒性越强；强度越低，水印越隐蔽但鲁棒性越弱

**3.2.1.4 水印加密（可选）**
  - 提供密钥输入框，用户可选择是否输入密钥
  - 若用户输入密钥，则对水印进行加密处理
  - 若用户不输入密钥，则不启用加密功能

**3.2.1.5 嵌入处理与下载**
  - 用户点击「开始嵌入」按钮，系统对上传的载体文件批量嵌入水印
  - 处理完成后，用户可下载已嵌入水印的文件
  - 批量处理时，支持打包下载所有处理后的文件

#### 3.2.2 水印提取界面

**3.2.2.1 载体文件上传**
  - 支持上传已嵌入水印的图片、音频、视频文件
  - 支持批量上传多个文件

**3.2.2.2 水印解密（可选）**
  - 提供密钥输入框，用户可选择是否输入密钥
  - 若水印嵌入时使用了加密，用户需输入正确密钥才能提取水印
  - 若水印嵌入时未加密，用户无需输入密钥

**3.2.2.3 提取处理与结果展示**
  - 用户点击「开始提取」按钮，系统从上传的文件中提取水印
  - 提取完成后，展示水印内容（文字、图片、音频、视频）
  - 批量处理时，逐一展示每个文件的提取结果

#### 3.2.3 攻击模拟界面

**3.2.3.1 载体文件上传**
  - 支持上传已嵌入水印的图片、音频、视频文件
  - 支持批量上传多个文件

**3.2.3.2 攻击类型选择**
  - 提供攻击类型选项，用户可选择一种或多种攻击方式：
    - 格式转换（如JPG转PNG、MP3转WAV等）
    - 裁剪（对图片或视频进行裁剪）
    - 噪声添加（添加高斯噪声、椒盐噪声等）
    - 压缩（降低文件质量或码率）
    - 旋转/缩放（对图片或视频进行旋转或缩放）

**3.2.3.3 攻击参数设置**
  - 根据选择的攻击类型，提供对应参数设置控件
  - 示例：裁剪比例、噪声强度、压缩质量等

**3.2.3.4 攻击处理与水印验证**
  - 用户点击「开始攻击」按钮，系统对上传的文件执行选定的攻击操作
  - 攻击完成后，自动尝试从攻击后的文件中提取水印
  - 展示攻击后的文件与提取结果，用户可判断水印是否仍可提取
  - 批量处理时，逐一展示每个文件的攻击结果与水印提取结果

## 4. 业务规则与逻辑

### 4.1 载体与水印类型匹配规则
- 图片载体：可嵌入文字、图片水印
- 音频载体：可嵌入文字、音频水印
- 视频载体：可嵌入文字、图片、音频、视频水印

### 4.2 批量处理规则
- 用户上传多个文件时，系统按顺序逐一处理
- 每个文件处理完成后，更新处理进度
- 所有文件处理完成后，提供批量下载或逐一下载选项

### 4.3 水印强度调节规则
- 强度阈值范围：1-10（1为最弱，10为最强）
- 用户可通过滑块或输入框设定强度值
- 强度值影响水印嵌入的深度与鲁棒性

### 4.4 水印加密规则
- 用户输入密钥时，系统对水印内容进行加密后再嵌入
- 提取水印时，若水印已加密，用户需输入正确密钥才能解密并提取
- 密钥错误时，提取失败并提示用户

### 4.5 攻击模拟规则
- 用户可选择单一攻击或组合攻击
- 攻击完成后，系统自动尝试提取水印，验证水印鲁棒性
- 若水印仍可提取，说明水印具备对该攻击的鲁棒性

---

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 用户上传不支持的文件格式 | 提示用户文件格式不支持，列出支持的格式 |
| 用户未选择水印类型或未上传水印内容 | 提示用户完成必填项 |
| 用户未上传载体文件 | 提示用户上传载体文件 |
| 水印提取时密钥错误 | 提示用户密钥错误，无法提取水印 |
| 水印提取失败（文件未嵌入水印或水印已损坏） | 提示用户未检测到水印或水印已损坏 |
| 攻击模拟后水印无法提取 | 展示提取失败结果，说明水印未通过该攻击测试 |
| 批量处理时部分文件处理失败 | 标记失败文件，提示用户查看失败原因，其他文件正常处理 |

---

## 6. 验收标准

1. 用户打开水印嵌入界面，上传一张图片，选择文字水印类型并输入文字内容，设定水印强度为5，点击「开始嵌入」，下载已嵌入水印的图片
2. 用户打开水印提取界面，上传刚才下载的已嵌入水印的图片，点击「开始提取」，成功提取并展示嵌入的文字内容
3. 用户打开攻击模拟界面，上传已嵌入水印的图片，选择「噪声添加」攻击类型，设定噪声强度为中等，点击「开始攻击」，系统执行攻击并自动提取水印，展示攻击后的图片与水印提取结果
